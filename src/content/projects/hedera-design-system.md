A design system for Hedera Dx's software portfolio, built on top of MUI, and the foundation for the new [Prime interface](#hedera-prime-ui). It has 42 components, from buttons and data grids to domain-specific ones such as gene tags and classification and therapy indicators.

The goal was to make new interfaces quick to build, whether a person or an AI coding agent writes them: a set of well-designed components that combine into any screen across the portfolio.

Every component is documented and tested in Storybook, with visual tests in Chromatic.
